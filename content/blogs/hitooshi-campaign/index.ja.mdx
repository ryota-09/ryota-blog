普段は都内でエンジニアとして働いています！ヒトオシを5〜6ヶ月使って卒業した元利用者でもあります。

今回は **2026年11月時点でヒトオシに入るときに使える割引** を、公式サイトと会員向けページを見ながら整理していきます！

先に結論です。11月6日に公式サイトを開いたら、関西・東海に住んでいる人限定で「入会金無料キャンペーン」が始まっていました。入会金17,800円が0円になって、締切は12月6日(日)です。

関東に住んでいる人は対象外なので、これまでどおり招待コードの入会金5,000円引きが一番安い入り方です。

それと、ひとつ謝らせてください。11月1日の更新で「今は期間限定のキャンペーンなし」と書いたのですが、その数日後にこのキャンペーンが始まっていました。いつ始まったのかは後で詳しく書きます。

## 関西・東海限定の入会金無料キャンペーン【12月6日まで】

公式サイトのトップと料金表に出ているキャンペーンの中身は、こうなっています。

| 項目 | 内容 |
| --- | --- |
| 名前 | 入会金無料キャンペーン(料金表の吹き出しでは「婚活応援キャンペーン」) |
| 割引 | 入会金17,800円 → 0円 |
| 対象 | 関西エリア(大阪・京都・兵庫・滋賀・奈良・和歌山)と東海エリア(愛知・岐阜・三重・静岡)に住んでいる人 |
| 適用条件 | 基本情報の登録と、初回面談の予約を済ませること |
| 締切 | 12月6日(日)まで |
| 月会費 | 割引なし(17,800円のまま) |

男女の指定はありません。8月の夏休みキャンペーンは2ヶ月目の月会費も半額になりましたが、今回は入会金だけです。

気をつけたいのは、適用条件が「初回面談の予約完了」になっているところです。入会の申し込みだけでなく、面談の予約まで12月6日までに済ませておく必要があります。夏休みキャンペーンのときは「面談の日付そのものは締切のあとでもOK」と公式が書いていましたが、今回はそこまでの記載が見当たりませんでした。締切ギリギリに申し込む場合は、公式LINEで念のため確認しておくと安心です。

## U29キャンペーン（29歳以下の女性向け）

満29歳以下の女性向けに、入会金が5,000円引きの12,800円になるU29キャンペーンは、11月6日時点で公式トップページから表示が消えていました。11月1日には載っていたものです。

一方で、女性向けの広告用ページにはU29のバナーがまだ残っています。それと、過去に関西・東海の企画をやっていた時期には「※本キャンペーンは関東エリア限定となります」と注記されたU29の画像が使われていました。関西・東海の企画と入れ替わりで、U29は関東の人向けに絞られる運用なのかもしれません。

いずれにしても、関東の29歳以下の女性は、U29でも招待コードでも入会金は12,800円で同じです。U29が使えるかどうかを気にする必要はあまりなくて、招待コードを入れておけば5,000円は引かれます。

年齢まわりの要件や、どの地域から使えるかは[対応エリアと入会条件の記事](/ja/blogs/zakki/hitooshi-eligibility)で詳しく書いています。

## 年明けのキャンペーンを待つべき？

これは住んでいる場所で答えが変わります。

関西・東海に住んでいる人は、待つ理由はあまりないと思います。今回のキャンペーンで入会金はもう0円になるので、年明けに全員向けの大型企画が来たとしても、上乗せされるのは2ヶ月目の月会費半額の8,900円分だけです。来るかどうかわからない8,900円のために2ヶ月待つよりは、12月6日までに面談の予約まで済ませてしまうほうがいいと思います。

関東に住んでいる人は、正直迷うところです。

年明けには2年続けて企画が出ています。2026年は年明け早々に公式Xで「2026婚活スタートキャンペーン」の告知があり、全員が入会金無料＋1ヶ月半額(2ヶ月目の月会費が半額)でした。2025年の1月にも、年始の割引キャンペーンを紹介している利用者のブログがあります。

全員向けの大型企画は、入会金17,800円が0円になって、2ヶ月目の月会費も半額の8,900円引き。合わせて26,700円お得です。招待コードの5,000円引きと比べると、差は21,700円あります。お金だけで考えるなら「急いでいないなら年明けまで待つ」はアリです。

ただ、次の年明けにやるという告知は今のところ何もないです。来なかったら2ヶ月待っただけになりますし、その間に出会えたかもしれない人とも会えません。ヒトオシは毎月2人を紹介してくれる仕組みなので、2ヶ月遅れれば4人と会う機会がまるごと後ろにずれる計算です。

僕なら、「今月から動きたい気持ちがある」なら招待コードで始めて、「年明けからでいいかな」くらいの温度感なら待つ、で分けると思います。

もう1つ、割引と同じくらい気になるのは「実際にどんな人と会えるのか」ですよね。[在籍している会員の年齢層・容姿のリアル](/ja/blogs/zakki/hitooshi-members)も公開しているので、申し込み前にのぞいてみてください。

面談を受けてみて合わないと感じたら、そこで正式入会しない選択もできます。実際に使ってどうだったかは[体験談の記事](/ja/blogs/zakki/hitooshi-review)に書いているので、判断材料にしてみてください。
